# Stellar Thread

Open-source interstellar messaging simulator and radio-astronomy DSP lab with reproducible data, propagation models, and explicit no-transmission safety gates.

## Current status

The full implementation is proposed in [PR #1](https://github.com/simondalmasso/Stellar-thread/pull/1) and remains under review. The current `main` branch is only this minimal project landing page; product features described in the PR are **not yet part of `main`**.

There is no verified production deployment, no connected live observatory, no public Voyager engineering telemetry, and no physical RF or optical transmission.

## What it is

- A proposed, reproducible software lab for interstellar-message encoding, propagation modelling, and radio-astronomy DSP.
- A place to inspect documented data provenance and explicit scientific/safety boundaries.
- An open-source project licensed under MIT; see [LICENSE](LICENSE).

## What it is not

- Not a service for communicating with extraterrestrial beings.
- Not connected to private Voyager engineering telemetry and cannot control or repair Voyager.
- Does not transmit radio-frequency signals or optical pulses.
- A hash or a simulation is not proof that a physical transmission occurred.

## Implementation under review

See [PR #1](https://github.com/simondalmasso/Stellar-thread/pull/1) for the proposed implementation, technical documentation, tests, and CI evidence. Until that PR is reviewed and merged, do not treat its features or documents as available on `main`.
