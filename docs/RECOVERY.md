# Recovery

Record repository SHA, Worker version/deployment ID and artifact hash after deployment. Recovery is a code rollback plus Worker version rollback; there is no baseline database to migrate. Candidate/import manifests are immutable evidence and should be backed up separately. Never rewrite a proof-of-transmission record; append a correction with references.
