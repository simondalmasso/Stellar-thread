# Radio Transmission

The application exports a proposal containing target coordinates, encoding profile, payload hash, carrier/modulation/repetition placeholders, schedule, regulatory approval, facility approval and provenance. The proposal is blocked unless every approval is present.

A facility adapter must run outside `PUBLIC_WEB`, authenticate an operator, require a per-run human approval, validate band/power/mode/call-sign requirements, protect radioastronomy bands, perform a link budget and produce signed proof-of-transmission. No browser-to-transmitter path is designed.

## Estado de verdad

Este documento distingue datos oficiales, derivados, observaciones auténticas grabadas, pruebas sintéticas, revisión humana y datos no disponibles. Ningún pico, score o coincidencia se presenta como mensaje extraterrestre.
