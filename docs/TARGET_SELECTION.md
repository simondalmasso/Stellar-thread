# Target Selection

The versioned snapshot contains Proxima Centauri b, GJ 273 b, Ross 128 b, Teegarden's Star b, TRAPPIST-1 e and LHS 1140 b. Score inputs are proximity, confirmed-exoplanet status, declination/facility visibility, scientific interest and available prior context. A score is a prioritization aid, never a habitability claim.

Before operational scheduling, refresh coordinates, distance, proper motion and ephemeris through NASA Exoplanet Archive plus SIMBAD/Gaia, record the query, hash the response and recompute visibility from the exact facility.

## Estado de verdad

Este documento distingue datos oficiales, derivados, observaciones auténticas grabadas, pruebas sintéticas, revisión humana y datos no disponibles. Ningún pico, score o coincidencia se presenta como mensaje extraterrestre.
