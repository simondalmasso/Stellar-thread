# Candidate Lifecycle

States follow the master specification. Automatic processing may produce `RFI_LIKELY`, `UNCLASSIFIED_EVENT`, `TECHNOSIGNATURE_CANDIDATE`, `REPEAT_DETECTED` or `MULTI_STATION_COINCIDENCE`. `CONFIRMED_EXTRATERRESTRIAL` requires repeated localization, coherent Doppler, satellite/aircraft/terrestrial exclusions, on/off-source tests, another facility, public data and external scientific review. The API rejects direct automatic assignment.

## Estado de verdad

Este documento distingue datos oficiales, derivados, observaciones auténticas grabadas, pruebas sintéticas, revisión humana y datos no disponibles. Ningún pico, score o coincidencia se presenta como mensaje extraterrestre.
