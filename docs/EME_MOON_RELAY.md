# EME Moon Relay

EME uses the Moon as a passive reflector. At the mean lunar distance of 384,400 km, the vacuum round trip is approximately 2.565 seconds; real sessions require current lunar range, Doppler, libration, polarization, sky noise, path loss and station geometry.

The current mode calculates demonstrator geometry and prepares the data model. A real session requires an authorized amateur station/operator, allowed band and emission, station identification, time window, antenna plan, waveform export, recording, decoded payload, original/received hashes, BER and FEC report. No RF was emitted by this project.

## Estado de verdad

Este documento distingue datos oficiales, derivados, observaciones auténticas grabadas, pruebas sintéticas, revisión humana y datos no disponibles. Ningún pico, score o coincidencia se presenta como mensaje extraterrestre.
