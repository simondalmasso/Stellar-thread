# Privacy

The baseline stores no accounts, personal messages or location history. Cloudflare request logs may contain standard request metadata according to the deployment account configuration. Community nodes must disclose station coordinates; an operator may publish coarse coordinates until scientific follow-up requires exact location under an approved policy.

## Estado de verdad

Este documento distingue datos oficiales, derivados, observaciones auténticas grabadas, pruebas sintéticas, revisión humana y datos no disponibles. Ningún pico, score o coincidencia se presenta como mensaje extraterrestre.
