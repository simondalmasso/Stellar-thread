# RFI Rejection

Baseline controls: compare on-source and off-source dominant frequencies; require independent stations for geographic coincidence; preserve station position/clock/calibration metadata; inspect satellites, aircraft and known emitters before promotion; repeat the observation.

The current algorithm marks a shared on/off-source dominant carrier `RFI_LIKELY`. This is intentionally conservative and incomplete. Facility-grade processing must add barycentric drift expectations, occupancy databases, polarization, beam-pattern tests, time-frequency morphology and external follow-up.

## Estado de verdad

Este documento distingue datos oficiales, derivados, observaciones auténticas grabadas, pruebas sintéticas, revisión humana y datos no disponibles. Ningún pico, score o coincidencia se presenta como mensaje extraterrestre.
